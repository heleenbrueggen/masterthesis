So, especially in the smaller datasets there is a high amount of singular fits. “Complex mixed-effect models (i.e., those with a large number of variance-covariance parameters) frequently result in singular fits, i.e. estimated variance-covariance matrices with less than full rank. Less technically, this means that some”dimensions” of the variance-covariance matrix have been estimated as exactly zero. For scalar random effects such as intercept-only models, or 2-dimensional random effects such as intercept+slope models, singularity is relatively easy to detect because it leads to random-effect variance estimates of (nearly) zero, or estimates of correlations that are (almost) exactly -1 or 1. However, for more complex models (variance-covariance matrices of dimension >=3) singularity can be hard to detect; models can often be singular without any of their individual variances being close to zero or correlations being close to +/-1.”

Code 
repca <- list()
sdev <- list()
explained_variance <- list()
for (i in seq_len(nrow(combinations))) {
    repca[[i]] <- map(analyses[[i]], ~ rePCA(.x))
    sdev[[i]] <- map(repca[[i]], \(x) x$group$sdev)

    explained_variance[[i]] <- map(sdev[[i]], \(x) (x)^2 / sum((x)^2)) %>% as.data.frame()
    colnames(explained_variance[[i]]) <- c(paste(1:100))

    explained_variance[[i]] <- explained_variance[[i]] %>%
        mutate(mean = rowMeans(explained_variance[[i]]))
}
meanexplvar <- cbind(explained_variance[[1]]$mean, explained_variance[[2]]$mean, explained_variance[[3]]$mean, explained_variance[[4]]$mean, explained_variance[[5]]$mean, explained_variance[[6]]$mean, explained_variance[[7]]$mean, explained_variance[[8]]$mean) %>%
    as.data.frame() %>%
    mutate(PC = paste0("PC", 1:4)) %>%
    pivot_longer(cols = -PC, names_to = "dataset", values_to = "var_explained")

sdev <- list()

sdev <- map(seq_len(nrow(combinations)), function(i) {
    analyses <- read_rds(paste(path, "results/imputed/pmm/model_pmm_", names[i], ".rds", sep = ""))
    map(analyses, function(x) {
        map(x[[4]], function(y) {
            rePCA(y) %$% group$sdev
        }) %>%
            map_dfr(., ~ as.data.frame(t(.x))) %>%
            colMeans()
    })
})

        mutate(mean = rowMeans(explained_variance[[i]]))
}
